# Agent Skills

Project-specific skills for `go-serve`.

| Skill | Use when |
|---|---|
| `architecture` | Changing package boundaries or overall design |
| `configuration` | Changing config parsing, validation, snapshots, or API config |
| `data-plane` | Changing routing, proxying, limits, upstreams, retries |
| `control-plane` | Changing admin APIs, health, OpenAPI, pprof |
| `authentication` | Changing OIDC, OAuth2, sessions, bearer auth, scopes |
| `clustering` | Changing Raft, peers, assignments, or VIP hooks |
| `observability` | Changing logging, metrics, counters, request tracking |
| `testing` | Adding/changing tests or validation workflows |
| `documentation` | Updating docs, OpenAPI, examples, changelog |
| `development` | Local build/run/development setup |
| `security` | Security-sensitive changes or reviews |
| `workflow` | General contributor/agent workflow and PR completion |
| `troubleshooting` | Diagnosing common local/runtime failures |

Read the most specific skill(s) before editing the corresponding subsystem.
